SVG logos from [Devicon](https://github.com/devicons/devicon), pinned to commit
`6a37858047b0e8d9c9c0e68f4a071fc410652e89`.

Each `<name>.svg` is copied from `icons/<name>/<name>-original.svg` in that
repository. The MIT license is included in `LICENSE.txt`. Product logos belong
to their respective owners and are used to identify skills.

Pascal and Sublime use the installed Lucide code/file-code icons. New skills
without a local icon use the code icon as a fallback.
